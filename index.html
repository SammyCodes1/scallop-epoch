The market

Built like a money market

Trilinear interest

The rate moves with how full the pool is.

Collateral and borrow weights

You borrow a fraction of collateral value. A volatile asset uses more of that room than a stablecoin.

Segregated collateral

Collateral sits in its own pool and does not earn supply yield. Yield comes from the lending pool.

Soft liquidation

A position can be eased down as risk rises, ahead of a full close-out.

Outflow limits

Each asset has a cap on how much can leave through borrows and withdrawals.

Sub-accounts

One address can run up to five obligation accounts, each with its own risk.

For builders

Python SDK

Read mainnet from Python. The published package is an alpha, so the install command below includes the pre-release flag. The sample only reads total value locked.

pip install --pre sui-scallop-sdk
from sui_scallop_sdk import ScallopClient

client = ScallopClient(network="mainnet")
query = client.create_query()
print(query.get_tvl().total_value)
